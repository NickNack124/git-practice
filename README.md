# git-practice
This repository contains two scripts:

- hello.py;
    a test script that just prints "Hello, Git!"

- check_sensors.py; 
    a script that checks whether certain sensor readings meet a certain threshold, and appends the ones that do to a json array.

Required input files:
- calibrations.csv
- sensors.xlsx
- config.yml

The input files must be in same repository, or at least same parent folder.

The input data files are not included in this repository.

The resulting JSON file should appear in the repository.
